# Game AI 基礎概念：遊戲中的 NPC 如何做出決策？

## 1. 什麼是 Game AI？

Game AI（Game Artificial Intelligence，遊戲人工智慧）是指遊戲中用來控制角色、敵人或其他遊戲物件行為的技術。

它的主要目的，是讓遊戲中的角色能夠根據目前的環境與條件，選擇適當的行動。

例如，在 RPG 遊戲中，敵方 NPC 可能會：
- 在沒有發現玩家時持續巡邏。
- 發現玩家後開始追逐。
- 玩家進入攻擊範圍後發動攻擊。
- 失去玩家蹤影後重新尋找或回到巡邏狀態。

這些看似具有智慧的行為，通常是透過程式規則與演算法設計出來的。

## 2. Sense / Think / Act：遊戲 AI 的基本循環

遊戲 AI 可以用三個階段來理解：

### Sense（感知）
取得遊戲環境中的資訊，例如玩家的位置、敵人的距離、角色生命值等。

### Think（決策）
根據取得的資訊，判斷目前應該採取什麼行動。

### Act（行動）
執行決策，例如移動、攻擊、逃跑或巡邏。

完成行動後，遊戲環境可能發生改變，因此角色會再次取得資訊並進行下一輪決策。

## 3. 為什麼遊戲需要 AI？

遊戲 AI 不一定是為了讓 NPC 變得像人類一樣聰明，而是為了讓遊戲體驗更有趣、更自然。

常見目的包括：

- **增加挑戰性：** 讓敵人能夠追蹤玩家、攻擊或躲避。
- **增加真實感：** 讓 NPC 的行為看起來更符合遊戲情境。
- **改善遊戲體驗：** 讓角色能根據玩家行動做出不同反應。
- **控制遊戲難度：** 讓敵人的行為具有適當的挑戰，而不是永遠採取最強策略。

## 4. 常見的 Game AI 技術

本知識庫將進一步介紹以下技術：

| 技術 | 主要用途 |
|---|---|
| Finite State Machine（FSM） | 管理 NPC 的不同狀態與狀態轉換 |
| Behavior Tree（BT） | 組織 NPC 的決策與行為邏輯 |
| A* Pathfinding | 尋找從起點到目標的路徑 |
| Steering Behaviors | 控制角色移動、追蹤與閃避 |

這些技術可以分別處理 NPC 的決策與移動問題，也可以在同一個遊戲角色中搭配使用。
